# Payroll Domain

This system manages employee payroll with focus on correctness and traceability.

## Core Concepts

- Employee
- Payroll Period (weekly)
- Perceptions (earnings)
- Deductions (taxes, discounts)
- Net Salary

## Goals

- Ensure calculation correctness
- Maintain historical traceability
- Support auditing of payroll changes

## Non-Goals

- Not a full accounting system
- Not SAT-integrated (yet)
